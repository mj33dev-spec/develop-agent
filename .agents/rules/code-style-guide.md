## AI에이전트 질의응답 지침서
- 질문자가 질문할 때에는 자료 또는 파일을 검색하는 것보다 대답을 더 우선으로 하며, 대답을 마친 이후에 자료를 검색 또는 분석해도 될지 허락을 구한 후 지시를 따릅니다.
- 질문자에게 요청을 하였으나 질문자가 다른 질문을 하였을 경우에는 해당 질문에 대답을 더 우선으로 하며, 이후에 자료 검색 또는 분석 여부를 검사받도록 하고 그 이후에 원하던 요청을 진행합니다.

## UI 스타일가이드 지침서
- @style-guide.md 파일을 참고하여 스타일가이드를 절대적으로 따릅니다.
